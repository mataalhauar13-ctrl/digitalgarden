# 学中文的开始

马丁是一名留学生，因为对**汉字感兴趣**，他从三年前开始学中文。

一开始，他只是在家自学。后来，为了能够**开口说中文**，他报了一个中文班。

- 每周两节课。
- 每节课一个半小时。

因为马丁很喜欢中文，在课堂上和在家里他都学习得很努力，所以他**进步非常快**。只用了一年左右的时间，他就可以用中文对话了。

# 去中国留学的决定

但是，马丁希望把中文说得更好。他觉得，**学习一门外语最好的方法，就是去那个国家生活一段时间**，所以他决定去中国留学。

于是，马丁一个人来到了北京。

# 刚到中国时的感受

刚到中国的时候，他对一切都很好奇。这里的生活和他想象的完全不一样。

他觉得很难听懂中国人说话，因为他们说得太快了，而且很多词他都没有在课本里学过。

但是，身边的人对他都很好。当马丁说“您能不能说得慢一点”或者“我没有听懂”的时候，大家总是慢慢地给他再重复一遍，和他解释每个单词的意思。

# 在中国的生活与进步

在中国生活的这段时间，马丁的中文**进步得很快**。他还认识了很多新朋友。

- 有的是中国人。
- 有的和他一样，是来自其他国家的留学生。

他们的共同爱好是**学习语言和旅行**。他们经常在一起学习，**互相帮助**，假期的时候还会去中国的其他城市旅游。

# 未来的希望

明年马丁就要回国了。他希望回国后可以做一名**中文老师**，和学生们分享自己的学习经验，教大家如何说好中文。
